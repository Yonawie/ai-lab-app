# AI Lab: запуск в классе с одной общей SQLite-базой

Этот вариант нужен для завтрашнего LAN-пилота: несколько компьютеров запускают AI Lab, но пишут в один файл базы на компьютере учителя.

## Важно

- Все компьютеры должны быть в одной локальной сети.
- Компьютер учителя должен быть включён всё занятие.
- Общая папка должна быть доступна ученикам на чтение и запись.
- SQLite через сетевую папку подходит только для пилота. Если одновременно пишет много учеников, возможны задержки или блокировки.
- Для реальных AI-ответов на каждом ученическом компьютере должен быть установлен Ollama и модель `qwen3:8b`. Если модели нет, используйте браузерный демо-режим или главный компьютер учителя.

## 1. На компьютере учителя

Открой PowerShell от имени администратора и запусти:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\pilot\prepare-shared-db.ps1
```

Скрипт:

- создаст папку `C:\AI-Lab-Shared`;
- скопирует туда текущую базу `dev.sqlite`;
- создаст сетевую шару `AI-Lab-DB`;
- покажет путь вида `\\TEACHER-PC\AI-Lab-DB\dev.sqlite`.

Перед уроком сделай резервную копию:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\pilot\backup-shared-db.ps1
```

## 2. На ученических компьютерах

Если запускаешь из установленного приложения:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\pilot\start-installed-with-shared-db.ps1 -SharedDbPath "\\TEACHER-PC\AI-Lab-DB\dev.sqlite"
```

Если запускаешь из репозитория в dev-режиме:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\pilot\start-dev-with-shared-db.ps1 -SharedDbPath "\\TEACHER-PC\AI-Lab-DB\dev.sqlite"
```

Замени `TEACHER-PC` на имя компьютера учителя или IP-путь, если так удобнее.

## Быстрая проверка перед занятием

1. На компьютере учителя открой путь `\\TEACHER-PC\AI-Lab-DB\dev.sqlite`.
2. На одном ученическом компьютере запусти AI Lab через скрипт.
3. Зарегистрируй ученика `student-test@class.local`.
4. На втором компьютере попробуй войти этим же email/паролем.
5. Если вход работает, значит общая база подключена.

## Если что-то пошло не так

- Если пишет “нет доступа”, проверь права общей папки.
- Если пишет “database is locked”, попроси учеников не нажимать сохранение одновременно и повторить через несколько секунд.
- Если AI-ответы не генерируются, проверь `ollama list` на этом компьютере.
- Если времени мало, веди урок через браузерный демо-режим: регистрация, Prompt Lab, Примеры обучения и Compare уже имеют безопасный демо-путь.
