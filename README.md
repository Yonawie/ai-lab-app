# AI Lab

AI Lab — учебное desktop-приложение, в котором школьники изучают искусственный интеллект через практику.

Главная идея курса: ученик не только знакомится с нейросетями, но и создаёт собственного AI-помощника, проверяет его поведение, а затем использует его для разработки небольшого инструмент-приложения.

## Что уже есть

- курс из шести практических занятий: от алгоритмов и машинного обучения до создания собственного AI-продукта;
- личный кабинет ученика с прогрессом и учебными заданиями;
- кабинет преподавателя и управление группами учеников;
- AI Studio и пространство для экспериментов с моделями;
- Prompt Lab, сравнение моделей, оценка качества и AI-экзамен;
- создание и обучение персонального AI Companion;
- практики классификации, очистки данных, обучения диалоговой модели и финальная миссия;
- локальный desktop-клиент на Tauri + React;
- серверная часть и локальное хранилище на Prisma/SQLite;
- интеграция с Ollama для локального запуска моделей.

## Учебный сценарий

1. Ученик выбирает задачу и формулирует роль будущего помощника.
2. Собирает примеры, правила и ограничения поведения.
3. Тестирует помощника в Prompt Lab и сравнивает результаты.
4. Проходит оценивание и улучшает модель по обратной связи.
5. Создаёт финальный инструмент — приложение, которое решает выбранную задачу.

## Технологии

TypeScript, React, Vite, Tauri, Rust, pnpm workspaces, Turborepo, Prisma, SQLite, Ollama.

## Запуск

```bash
pnpm install
pnpm db:generate
pnpm db:push
pnpm desktop:dev
```

Для локальной работы моделей требуется установленный Ollama. Переменные окружения для базы данных находятся в `packages/database/.env.example`.

## Структура

- `apps/desktop` — Tauri/React приложение;
- `packages/core` — доменная логика;
- `packages/database` — Prisma-схема, миграции и read-models;
- `packages/ui` — общие UI-компоненты;
- `packages/lan-server` — локальный сервер;
- `tools/training` — инструменты обучения и регистрации адаптеров;
- `tools/n8n` — сценарии автоматизации и AI-агенты.

Проект развивается как учебная лаборатория: каждая новая возможность должна давать ученику наблюдаемый результат и вести к финальному AI-продукту.
